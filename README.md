# LogPipe

A lightweight developer tool for collecting and streaming logs from local projects.

## Overview

LogPipe aims to make application logs easier to collect, inspect, and stream across local development environments.

## Planned Features

- Local log collection
- Real-time log streaming
- Node.js and Go project support
- Service discovery
- LAN-based log monitoring
